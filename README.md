# NEXORA TECH — BRAND IDENTITY

## 1. Company Name
**Official Name:** Nexora Technologies  
**Brand Name:** Nexora Tech

**Company Description:**  
Nexora Tech is a technology and innovation company focused on developing modern digital solutions that help individuals and businesses solve problems, improve productivity and embrace the future of technology.

**Brand Personality:** 
- Innovative
- Modern
- Professional
- Creative
- Reliable
- Forward-thinking

---

## 2. Company Colour Palette

Nexora Tech will use a modern combination of deep navy blue, electric cyan, vibrant blue, white and soft grey.

| Colour Name | HEX Code | Purpose |
|---|---|---|
| Midnight Navy | `#0B1220` | Primary brand colour and navbar |
| Deep Blue | `#142B4A` | Secondary backgrounds |
| Electric Cyan | `#00D4FF` | Highlights, icons and accents |
| Royal Blue | `#2563EB` | Buttons and interactive elements |
| Pure White | `#FFFFFF` | Text and clean backgrounds |
| Soft Grey | `#F1F5F9` | Light backgrounds and sections |
| Slate Grey | `#64748B` | Secondary text and descriptions |

### Colour Usage Guidelines
- **Midnight Navy:** Main identity colour, navigation bar and footer.
- **Deep Blue:** Secondary sections and cards.
- **Electric Cyan:** Important highlights, links and brand accents.
- **Royal Blue:** Primary buttons and calls to action.
- **Pure White:** Main text on dark backgrounds and clean content areas.
- **Soft Grey:** Light website sections and backgrounds.
- **Slate Grey:** Supporting text and descriptions.

---

## 3. Company Typography (Fonts)

Nexora Tech will use modern, clean and professional fonts to maintain consistency across its website, applications and marketing materials.

### Primary Font: Poppins
**Usage:** Headings, titles, navigation and important brand text.

### Secondary Font: Inter
**Usage:** Paragraphs, descriptions, buttons, forms and general website content.

### Technical Font: JetBrains Mono
**Usage:** Programming-related content, code snippets and technical information.

### Font Weights
- Regular: 400
- Medium: 500
- Semi-Bold: 600
- Bold: 700
- Extra-Bold: 800

---

## 4. Brand Design Principles

1. Maintain a clean and modern interface.
2. Use consistent colours throughout all company platforms.
3. Prioritise readability and accessibility.
4. Avoid unnecessary decorations and overcrowded layouts.
5. Maintain a professional and innovative appearance.
6. Ensure the website is responsive across mobile, tablet and desktop devices.
